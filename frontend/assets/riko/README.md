# Riko Character Assets

This directory stores the official 3D character renders and illustrations for **Riko — Your Opportunity Scout**.

## Supported Expression & Pose Slots:
- `happy.png` / `riko_welcome.png` — Welcome / Happy
- `excited.png` / `riko_opportunity.png` — New Opportunity / Excited
- `thinking.png` / `riko_search.png` — Searching / Thinking
- `helpful.png` / `riko_explaining.png` — Explaining / Helpful
- `celebrating.png` / `riko_achievement.png` — Achievement / Celebrating
- `surprised.png` / `riko_notification.png` — Important Notification / Surprised
- `waving.png` — Hello / Waving
- `pointing.png` — Let's Go / Pointing
- `laptop.png` / `riko_finding.png` — Finding opportunities / Holding laptop
- `sitting.png` — Waiting / Sitting
- `sleeping.png` — Idle / No new updates / Sleeping
- `tablet.png` — Helping / Suggesting / Using tablet
- `turnaround_front.png`, `turnaround_34.png`, `turnaround_side.png`, `turnaround_back.png`

## Fallback System
The application features a built-in `RikoAvatar`, `RikoHero`, `RikoIllustration`, and `RikoBadge` system with glowing aesthetic vector placeholders. When image assets are placed here, they will automatically be displayed without requiring UI redesigns.
